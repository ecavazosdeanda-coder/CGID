V2 RC3 incorpora comentarios pastorales en Biblia, Puntos de Fe y Literatura.

- Corrige la pantalla gris al inicializar el visor y permite regresar durante la carga o un error.
- PDF de hasta 100 MB, con recomendación de 20 MB y confirmación para publicar archivos grandes.

- Cualquier usuario puede leer los comentarios publicados de todas las iglesias y regiones para cada lectura. Filtros opcionales de iglesia, región, estado y ciudad.
- Pastores: redactan y gestionan sus propios comentarios de su iglesia. Administración: modera todos. Se puede publicar u ocultar sin borrar.
- Panel discreto que se abre y cierra a petición; no se proyectan comentarios junto con el contenido del culto.
- Literatura web: visor interno sin descarga offline, exportación ni selección de texto del PDF. Las aplicaciones instaladas conservan descarga interna para lectura offline.
- Incluye los cambios anteriores de verificación de correo, simulación de roles por dispositivo y publicación de literatura desde Drive.

La web está en https://cgdi-app-v2.web.app . Los paquetes siguientes corresponden
a la candidata V2; V1 no se modifica.

Paquetes de prueba sin firma de distribución:

- Android APK instalable y AAB: firma de depuración, para pruebas; una firma distinta a la instalación anterior puede requerir reinstalación. Respaldar datos locales antes de desinstalar.
- Windows: EXE instalable y ZIP portable; el sistema puede advertir que el editor no está verificado.
- macOS: DMG sin firma de distribución; Gatekeeper puede bloquearlo hasta que se permita su apertura.
- iOS: ZIP de la aplicación compilada sin firma. Requiere firma y aprovisionamiento de Apple antes de instalar en dispositivos; no es un IPA listo para instalar.
- Linux: bundle experimental, requiere GTK 3, MPV y GStreamer compatibles con el entorno de compilación. Firebase/Auth/Firestore no están disponibles de forma nativa; para comentarios sincronizados se recomienda la versión web.

La restricción de descarga web es una protección de interfaz, no DRM: la lectura
requiere transmitir el PDF al navegador y no impide capturas o extracción técnica.
No se activó Blaze ni facturación para esta publicación.
